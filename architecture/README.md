# 数据库设计 / Database Design

本目录展示项目的数据库设计材料。

This directory contains database design materials for the project.

## E/R Diagram

项目从 E/R 建模开始，对用户、好友关系、股票列表、投资组合、股票历史数据等核心实体及其关系进行建模。

The project begins with E/R modeling to represent the core entities and relationships, including users, friendships, stock lists, portfolios, stocks, and historical stock data.
